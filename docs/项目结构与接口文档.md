# 游戏对局记录分享平台 — 项目结构与接口文档

> 版本：v1.0 ｜ 日期：2026-10-05 ｜ 技术栈：Spring Boot 3.3.5 + MyBatis-Plus 3.5.7 + MySQL 8.0 + Vue 3.5 + Element Plus 2.9
> 本文档依据项目实际源码整理，接口字段与真实代码一一对应。



***

## 一、项目概述

### 1.1 架构

前后端分离的单体 Web 应用：



```
浏览器（Vue 3 前端）
   │  HTTP / JSON（开发环境经 Vite 代理）
   ▼
Spring Boot 后端（8080）
   ├── Controller（接口层）
   ├── Service（业务层）
   ├── Mapper（MyBatis-Plus 数据访问）
   └── MySQL 8（game_record 库，7 张表）
```



* **前端**：Vue 3 + Vite 5 + Element Plus + Axios + Vue Router，开发端口 5173，构建产物由 Nginx 托管（可选 Docker 部署）。

* **后端**：Spring Boot 3.3.5（JDK 17）、MyBatis-Plus、JWT 无状态认证、BCrypt 密码加密、SSE 实时推送、ffmpeg 视频封面抽帧。

* **鉴权**：JWT（HS256，默认 7 天有效），写请求强制登录，读请求匿名可访问（带 token 时回显点赞状态）。

### 1.2 功能清单



| 模块   | 说明                                                     |
| ---- | ------------------------------------------------------ |
| 用户   | 注册、登录（JWT）、个人中心、数据看板、玩家公开主页                            |
| 对局   | 上传（图片 / 视频 + 封面抽帧）、列表（搜索 / 筛选 / 排序 / 分页）、详情、编辑、删除、分享海报 |
| 评论   | 一级评论 + 楼中楼回复、评论配图、软删除、敏感词过滤                            |

### 2.4 数据库设计（game\_record 库，7 表）



| 表                | 说明    | 关键字段                                                                                                                                                                           |
| ---------------- | ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `user`           | 用户表   | username（唯一）、password（BCrypt）、nickname、avatar、role（user/admin）、create\_time                                                                                                    |
| `game_record`    | 对局记录表 | user\_id、game\_name、game\_mode、match\_date、result（win/lose/draw）、rank、description、tags（逗号分隔）、cover\_url、video\_url、like\_count、comment\_count、status（0 正常 / 1 下架）、create\_time |
| `comment`        | 评论表   | record\_id、user\_id、parent\_id（0 = 一级）、to\_user\_id、content（≤500）、image\_url、like\_count、deleted（软删除）、create\_time                                                             |
| `like_record`    | 点赞表   | user\_id、target\_id、target\_type（record/comment），**唯一约束 (user\_id,target\_id,target\_type) 防刷**                                                                                |
| `notification`   | 通知表   | user\_id（接收者）、actor\_id（触发者）、type（like/comment/reply）、content、target\_type/target\_id（跳转对局）、is\_read                                                                           |
| `report`         | 举报表   | record\_id、reporter\_id、reason、detail、status（0 待处理 / 1 已处理）、handle\_result、handle\_time                                                                                        |
| `sensitive_word` | 敏感词表  | word（唯一），初始 5 条：代练 / 加微信 / 赌博 / 诈骗 / 广告                                                                                                                                        |

索引：game\_record 有 user\_id /game\_name/create\_time /like\_count 索引；comment 有 record\_id /parent\_id；notification 有 (user\_id, is\_read)；report 有 record\_id /status。

### 2.5 关键设计说明



1. **JWT 认证**：登录签发 HS256 令牌（默认 168 小时有效），前端存 localStorage，请求头 `Authorization: Bearer <token>`。服务重启不失效。

2. **拦截规则**：`/api/**` 写请求（POST/PUT/DELETE/PATCH）必须登录，未登录 401；读请求匿名放行，带有效 token 时注入 `UserContext`（用于回显 "我是否已点赞"）。登录 / 注册接口排除。

3. **管理员权限**：举报处理、敏感词管理在 Service 层 `requireAdmin()` 校验 `role == admin`，非管理员返回 403。

4. **SSE 实时通知**：`GET /api/notification/stream?token=`（EventSource 无法带 Header，故 token 走 query）。后端按用户维护 SseEmitter 集合，点赞 / 评论 / 回复触发时推送 `unread` 事件，前端铃铛实时亮起。

5. **视频封面抽帧**：上传 mp4/mov 时 ffmpeg 抽取第 1 秒画面（避免首帧黑屏），失败换第 3 秒重试，封面 <1KB 视为无效；超时 60s。抽帧失败不阻断上传。

6. **敏感词过滤**：评论发布时逐条比对 `sensitive_word` 表，命中则替换为 `**`。

7. **软删除**：评论删除为软删（deleted=1），级联删除其回复；对局删除为物理删除并级联清理点赞 / 评论 / 通知。

8. **分享海报**：java.awt 绘制 PNG（标题 / 游戏名 / 作者 / 二维码占位），返回可访问 URL。

9. **防重复点赞**：`like_record` 唯一约束 + 事务回滚，重复点赞自动转为取消。

## 三、接口文档

### 3.1 通用约定

**Base URL**：`http://localhost:8080`（开发环境前端经 Vite 代理，请求写相对路径 `/api/...` 即可）

**统一响应格式**：



```
{ "code": 200, "message": "成功", "data": { ... } }
```



| code | 含义    | 说明                     |
| ---- | ----- | ---------------------- |
| 200  | 成功    | data 为业务数据（无数据时为 null） |
| 400  | 参数错误  | 参数缺失 / 格式错误 / 校验失败     |
| 401  | 未登录   | 未携带 token 或 token 失效   |
| 403  | 无权限   | 非本人资源 / 非管理员           |
| 404  | 资源不存在 | 对局 / 用户 / 评论等不存在       |
| 500  | 服务器错误 | 异常兜底                   |

**鉴权方式**：除注册、登录外，写请求（POST/PUT/DELETE）必须携带请求头：



```
Authorization: Bearer <登录返回的token>
```

**分页结果结构**（所有 list 接口通用）：



```
{ "list": [...], "total": 12, "page": 1, "size": 10 }
```

### 3.3 用户模块 `/api/user`

#### ① 注册 POST /api/user/register

请求体（JSON）：



| 字段       | 类型     | 必填 | 说明            |
| -------- | ------ | -- | ------------- |
| username | string | 是  | 用户名，≤50 字符，唯一 |
| password | string | 是  | 密码，6-50 字符    |
| nickname | string | 否  | 昵称，≤50 字符     |

响应 data（UserVO）：



```
{ "id": 5, "username": "player1", "nickname": "玩家一", "avatar": null, "role": "user" }
```

错误：400 用户名已存在 / 参数校验失败。

#### ② 登录 POST /api/user/login

请求体（JSON）：`{ "username": "player1", "password": "123456" }`

```
{
  "token": "eyJhbGciOiJIUzI1NiJ9...",
```

token 有效期默认 168 小时（7 天），前端存 localStorage。

### 3.4 对局模块 `/api/record`

#### ⑥ 上传对局 POST /api/record/upload

请求体为 `multipart/form-data`：



| 表单字段        | 类型     | 必填 | 说明                                         |
| ----------- | ------ | -- | ------------------------------------------ |
| file        | file   | 否  | 图片 (jpg/png/gif/webp) 或视频 (mp4/mov)，≤500MB |
| gameName    | string | 是  | 游戏名称，≤100 字符                               |
| gameMode    | string | 否  | 游戏模式（排位 / 匹配等），≤50                         |
| matchDate   | string | 否  | 对局日期 yyyy-MM-dd                            |
| result      | string | 否  | win / lose / draw                          |
| rank        | string | 否  | 段位，≤50                                     |
| description | string | 否  | 描述，≤2000                                   |
| tags        | string | 否  | 标签，逗号分隔（如 `翻盘,五杀`），≤255                    |

响应 data（RecordVO，见下）；视频自动抽帧生成封面（coverUrl），抽帧失败不影响上传。

#### ⑦ 对局列表 GET /api/record/list

Query 参数：



| 参数       | 类型     | 默认     | 说明                      |
| -------- | ------ | ------ | ----------------------- |

#### ㉔ 实时通知流（SSE）GET /api/notification/stream?token=xxx



* 鉴权：token 走 query 参数（EventSource 无法携带 Header）。

* 响应：`text/event-stream`，事件名 `unread`，data 为最新未读数 JSON。

* 触发时机：他人点赞 / 评论 / 回复自己的内容时实时推送；服务端超时（约 60s）自动重连。

前端用法：



```
const es = new EventSource(`/api/notification/stream?token=${token}`)
es.addEventListener('unread', (e) => { unreadCount.value = JSON.parse(e.data).unread })
```

## 四、快速验证

后端已启动时，可直接用 curl / Postman 验证：



```
# 注册
curl -X POST http://localhost:8080/api/user/register -H "Content-Type: application/json" -d "{\"username\":\"demo01\",\"password\":\"123456\",\"nickname\":\"演示\"}"
# 登录
curl -X POST http://localhost:8080/api/user/login -H "Content-Type: application/json" -d "{\"username\":\"demo01\",\"password\":\"123456\"}"
# 带 token 上传对局
curl -X POST http://localhost:8080/api/record/upload -H "Authorization: Bearer <token>" -F "file=@demo.mp4" -F "gameName=演示游戏"
# 匿名查看列表
curl "http://localhost:8080/api/record/list?page=1&size=10"
```
